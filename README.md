# QR GENERATOR

URL、テキスト、Wi-Fi の QR コードをブラウザ内で生成する静的アプリです。

```sh
npm install
npm run dev
npm test
npm run build
```

`dist/` を静的ホスティングに公開できます。相対パスでビルドするため GitHub Pages のプロジェクトサイトにも配置できます。

QR コードの生成と画像の書き出しはブラウザ内で行います。サイトアイコンを選択した場合のみ、URL のホスト名を画像プロキシ weserv.nl と DuckDuckGo の favicon サービスに送信します。取得できない場合は画像をアップロードしてください。

アップロードした SVG は SVG のまま埋め込まれます。外部の画像やフォントを参照する SVG は正しく表示されない場合があります。SVG は拡大可能なベクター形式、PNG は 2048 × 2048 ピクセルです。標準ではいずれも 4 モジュールの余白を含みます。詳細設定で余白をなくした場合は、配置先で周囲に 4 モジュール以上の明るい余白を設けてください。透過背景や画像の重ね合わせ、角丸の形状は読み取りに影響する場合があります。使用する背景や印刷サイズで読み取れるか確認してください。

「読み取りやすさ」は訂正余裕に基づく目安であり、各段階は実際のスキャン結果ではありません。訂正余裕は、画像領域と重なる符号語をすべて誤りと仮定し、最も余裕の少ない Reed–Solomon ブロックでさらに訂正できる符号語数を示す保守的な推定です。特殊パターンとの重なり、角丸、背景や印刷状態などは数値に含まれず、読み取りを保証するものではありません。
